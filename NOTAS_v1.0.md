AAMIX v1.0 para Windows

Descarga **AAMIX_Instalador.exe**, ábrelo y pulsa **Instalar**. Cuando termine, pulsa **Jugar**.

Para futuras versiones, abre el mismo instalador y pulsa **Actualizar**. La cuenta y el progreso se conservan.

Esta primera distribución utiliza el paquete oficial AAMIX v1.0. Incluye partidas individuales, Desafío AAMIX, multijugador, colección, sobres, misiones y tienda.

El ZIP completo se ofrece también como descarga portátil: extrae toda su carpeta y abre **AAMIX.exe**.
